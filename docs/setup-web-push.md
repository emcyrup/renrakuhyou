# アプリ通知（Web Push）の設定手順

外部サービスの契約が不要で、費用が 0 円の構成です。従業員はアカウント作成もアプリのインストールも行いません。

## 全体の流れ

1. サーバー側で VAPID 鍵を生成する（1 回だけ）
2. 従業員を「アプリ通知」で登録する
3. 従業員ごとの **通知設定 URL** を本人に渡す
4. 従業員が URL を開き、ホーム画面に追加して通知を許可する

## 1. VAPID 鍵の生成

```bash
npm run push:keys
```

出力された 3 行を `.env` に貼り付けます。

```env
VAPID_PUBLIC_KEY=BN...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:admin@example.co.jp
DEFAULT_PROVIDER=web_push
```

> **鍵は変更しないでください。** 変更すると、登録済みの端末すべてに通知が届かなくなり、全員に設定をやり直してもらう必要があります。バックアップ対象に含めてください。

## 2. HTTPS で公開する

**Web Push は HTTPS でのみ動作します**（`localhost` での開発時を除く）。
従業員のスマートフォンから到達できる HTTPS の URL を用意し、`.env` に設定してください。

```env
APP_BASE_URL=https://renrakuhyou.example.co.jp
```

この URL が、通知設定 URL と確認画面のリンクに使われます。

## 3. 従業員の登録

従業員画面で「サービス」に **アプリ通知（Web Push）** を選んで登録します。
**送信先 ID は空欄で構いません**（内部用の識別子が自動採番されます）。

レベル高の連絡では電話連絡を行うため、電話番号も登録しておいてください。

## 4. 通知設定 URL の配布

従業員画面の「通知設定」列に、本人専用の URL が表示されます。「コピー」ボタンで取得し、次のいずれかで本人に渡してください。

- QR コードにして掲示・配布する（現場では最も確実です）
- 既存の連絡手段（メール、SMS、紙）で渡す

> この URL は**本人であることの証明そのもの**です。他人に渡ると連絡内容を読まれるため、共有しないよう周知してください。

## 5. 従業員側の設定

### iPhone / iPad

**Safari で開く必要があります。** URL を開くと、画面に手順が表示されます。

1. 画面下の共有ボタン（□に↑のマーク）を押す
2. メニューを下にたどって「ホーム画面に追加」を選ぶ
3. 右上の「追加」を押す
4. ホーム画面にできた「連絡票」アイコンから開き直す
5. 「通知を有効にする」を押し、通知を「許可」する

**手順 4 を飛ばすと通知は届きません。** iOS ではホーム画面に追加した場合のみ Web Push が有効になるためです。

### Android

Chrome で URL を開き、「通知を有効にする」を押して通知を許可するだけです。
ホーム画面への追加は必須ではありませんが、追加しておくと開きやすくなります。

### 設定の確認

設定が終わると画面に「設定は完了しています」と表示されます。
「テスト通知を送る」ボタンで、実際に通知が届くかその場で確認できます。**導入時は必ず一度押してもらってください。**

## 6. 設定状況の確認（管理側）

- **ダッシュボード** … 端末が未登録の従業員がいる場合、警告として一覧表示されます
- **従業員画面** … 「通知設定」列に「設定済み（N 台）」または「未設定」が表示されます

**「未設定」の従業員には連絡が届きません。** 全員が「設定済み」になるまで追いかけてください。

## 従業員側の使い方

- 通知をタップすると、連絡の内容が表示されます
- 通知に表示される「確認しました」を押すと、**画面を開かずに確認を登録できます**（Android / PC。iOS では通知をタップして画面から確認します）
- ホーム画面のアイコンから開くと、自分宛の未確認の連絡が一覧で表示されます

## 仕組みと制約

- 通知は各ブラウザベンダーの push サービス（Apple / Google など）を経由します。本アプリのサーバーが直接端末へ送るわけではありません
- 通知の本文は端末ごとの鍵で暗号化され、push サービスからは内容を読めません
- 端末側で通知を解除したり、アプリを削除したりすると購読は失効します。失効した端末は送信時に自動で登録から削除されるため、管理画面では再び「未設定」として表示されます
- 機種変更をした場合は、新しい端末で通知設定 URL を開き直す必要があります

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| iPhone で「通知を有効にする」が出ない | Safari で開いているか、ホーム画面のアイコンから開き直したか |
| ボタンを押しても通知が届かない | 端末の設定 →「連絡票」→ 通知が許可されているか。集中モード／おやすみモードが有効になっていないか |
| 「通知設定が未完了です」というエラーで送信に失敗する | 本人がまだ設定を終えていません。通知設定 URL を再度案内してください |
| 全員に急に届かなくなった | `.env` の VAPID 鍵が変わっていないか。HTTPS でアクセスできているか |

送信の失敗理由は「送信ログ」画面に記録されています。
