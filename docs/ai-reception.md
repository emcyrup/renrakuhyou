# AI 受付（従業員の画面）の設定

従業員が開く `/enroll/<トークン>` は、受付のような 1 画面にまとまっています。

```
┌──────────────┬─────────────────────────┬──────────────────┐
│ 出勤する      │                          │ 本日の配車情報     │
│ 退勤する      │   選んだ操作の内容          │ 重要なお知らせ     │
│ 情報を確認する │   （点呼・連絡・報告・AI）   │ みんなの報告       │
│ 報告する      │                          │                  │
│ AI に質問する │                          │                  │
│ 設定         │  話しかける／キーボード入力   │                  │
└──────────────┴─────────────────────────┴──────────────────┘
```

上部には会社名・挨拶・時計・天気、左に大きな操作ボタン、右に情報欄が並びます。
スマートフォンでは同じ内容が縦に並びます。

## 1. 何ができるか

| 操作 | 内容 | 記録されるもの |
| --- | --- | --- |
| **出勤する / 退勤する** | 未確認の連絡を 1 件ずつ表示し、すべて確認してから出退勤を記録します。読み上げにも対応します | 点呼の時刻と、そのとき伝えた連絡の件数（確認者画面の「点呼」） |
| **情報を確認する** | 自分宛の連絡の一覧。開くと本文と「確認しました」 | 開封時刻・確認時刻（従来どおり） |
| **報告する** | 車両・道路・荷物・その他を会社へ報告。急ぎ指定と、仲間への共有を選べます | 報告の内容（確認者画面の「報告」） |
| **AI に質問する** | 会社の方針を持たせた AI が応対します | 質問と回答（続けて質問できます） |
| **設定** | 通知の設定と、お名前の変更 | — |

**事故や重要な連絡があるときは、キャラクターの表情と画面全体の色が変わります。**
対象は「未確認のレベル高の連絡」と「急ぎの報告（対応済みになるまで、最大 6 時間）」です。

## 2. 確認者側の設定

| 画面 | 設定すること |
| --- | --- |
| **設定** | 会社名 / 今日のひとこと / AI への指示 / 天気の地域コード |
| **配車情報** | その日の車番・区間・担当・備考。従業員の「本日の配車情報」に出ます |
| **報告** | 従業員から届いた報告の確認と、対応済みの記録 |
| **点呼** | その日の出勤・退勤の記録と、まだ点呼していない従業員 |

## 3. AI の設定（任意）

`ANTHROPIC_API_KEY` を `.env` に設定すると「AI に質問する」が使えます。未設定でも他の機能は動きます。

```bash
# サーバーで
sudo -u renrakuhyou nano /opt/renrakuhyou/.env
# ANTHROPIC_API_KEY=sk-ant-... を追記して保存
sudo systemctl restart renrakuhyou
```

キーは [Anthropic Console](https://console.anthropic.com/settings/keys) で発行します。

### 応対の方針を教える

確認者画面の **設定 →「会社からの指示」** に、社風や就業規則の要点を書きます。ここに書いた内容にそって応対し、
書かれていないことは推測せず「担当者に確認してください」と答えます。

```
・当社は安全最優先。無理な運行はしない。
・体調不良や事故のときは、まず安全確保のうえ運行管理者（06-xxxx-xxxx）へ電話。
・有給は 2 週間前までに申請書を提出。
```

> ⚠️ **個人情報や口座情報など、従業員に見せてよくない内容は書かないでください。** 全員の AI 応対に使われます。

AI には、その従業員の**今日の配車・未確認の連絡・仲間の報告・天気**も一緒に渡ります。
他の従業員宛の連絡や、報告のうち共有していないものは渡りません。

### 費用の目安と歯止め

- モデルは `claude-opus-5`、1 回の質問はおおよそ入力 1,000 トークン・出力 200 トークン程度です
- 1 回あたり **1 円前後**。1 日 100 回でも月 2,000〜3,000 円程度が目安です
- **1 人あたり 1 時間 30 回**を超えると、その人はしばらく質問できなくなります（暴走時の歯止め）
- 使わない場合は `ANTHROPIC_API_KEY` を設定しなければ 0 円です

## 4. 天気（費用 0 円）

気象庁の公開データを使うため、契約もキーも不要です。地域コードは確認者画面の「設定」で変更できます。

| 地域 | コード | 地域 | コード |
| --- | --- | --- | --- |
| 大阪府 | 270000 | 東京都 | 130000 |
| 兵庫県 | 280000 | 愛知県 | 230000 |
| 京都府 | 260000 | 広島県 | 340000 |
| 福岡県 | 400000 | 熊本県 | 430000 |

取得できているかは設定画面に表示されます（`npm run healthcheck` でも確認できます）。
サーバーから `https://www.jma.go.jp` へ通信できる必要があります。

## 5. キャラクターの画像

`public/mascot.png` を置くと、受付のキャラクターとして表示されます（正方形・512px 程度を推奨）。
置かない場合は簡易表示になります。

```bash
sudo -u renrakuhyou cp ~/mascot.png /opt/renrakuhyou/public/mascot.png
```

> 画像は `public/` に置くため、**デプロイ（git pull）で消えることはありません**が、git の管理外です。
> 別のサーバーへ移すときは手で持っていってください。

## 6. 声の入力・読み上げ

どちらもブラウザの機能で行うため、費用はかかりません。

- **声で話しかける**: Chrome（Android / PC）で使えます。**iOS の Safari は未対応**のため、キーボード入力の案内が出ます
- **連絡の読み上げ**: 点呼の画面で「声で読み上げる」を入れると、連絡を読み上げます

## 7. まだできないこと

- **基幹システムとの連携**（シフト・予定の自動取り込み）。今は確認者が配車情報を手で登録します
- **SMS 通知**
- 管理者の LINE 共有情報の自動取り込み。今は「今日のひとこと」や連絡として手で入力します
